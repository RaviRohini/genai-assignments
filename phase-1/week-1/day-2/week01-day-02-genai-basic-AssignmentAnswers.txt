2) Read 2–3 articles about how transformer works?
Goal to understand:
(a) Self-attention mechanism
(b) Vector embedding
(c) Feed forward Nueral Network


Answer:
Articles referred:
1. The illustrated Transformer - Jay Alammar - the classic visual deep-dive on self-attention
2. How Transformers work - DataCamp - full architecture walkthrough (updated Feb 2026)
3. Feed-Forward Networks in Transformers - Michael Brennodoefer - focused deep-dive on the FFN

1. Vector Embedding:
---------------------
--> Turns words into numbers.
--> Each token becomes a vector (size 512 in the original model) that captures meaning.
--> Similar words sit close together in "meaning space":
	king - man + woman = queen
	
--> Embedding happens only in the bottom encoder.
--> Positional Encoding (sine/cosine) is added so the model knows words order - since all words are processed in parallel.


2. Self-Attention:
-------------------
--> Each word looks at every other word to understand context.
--> In "... because it was tired", attention links "it" refers "animal".
--> Q, K, V = Query / Key / Value (like a database lookup):
	1. Make Q, K, V vectors per word
	2. Score = Q . K (dot product)
	3. Scale by squre root of 64 = 8
	4. Softmax -> weights sum to 1
	5. Weight & sum Values -> Output
Multi-Head: do this 8x in parallel; each head learns a different relationship.


3. Feed-Forward Network:
-------------------------
--> The transformer's "thinking" layer.
--> Refines each work independently after attention.
Why needed? Attention alone is linear.
--> The FFN adds non-linertiy - e.g, "bank" (money) vs "bank" (river).

Standard FFN Formula
---------------------
FFN(x)=W2σ(W1x+b1)+b2

Where:
x = input token embedding (or output from the attention layer)
W1,W2 = learnable weight matrices
b1,b2 = bias vectors
σ = activation function (typically ReLU or GELU)

In modern LLMs (e.g., GPT, Llama, Claude)
Most models use GELU instead of ReLU:
-------------------------------------
FFN(x)=W2GELU(W1x+b1)+b2

Intuition
--> Expand the input vector to a larger hidden dimension.
--> Apply a non-linear activation (GELU/ReLU).
--> Project it back to the original embedding dimension.

For example, if the embedding dimension is 4096, the FFN might expand it to 16384, apply GELU, and then project it back to 4096.


How It Fits Together - One Encoder Block
-----------------------------------------
Input word
	|
Embedding + Positional Encoding
	|
Self-attention (words share context)
	|
Add & Normalize (residual connection)
	|
Feed-Forwad Network (refine each word)
	|
Add & normalize
	|
Output -> next encoder


Key Takeaways
--------------
> Attention routes info
Words communicate with each other

> FFN transforms info
each word refined on its own

> Parallel, not sequential
unlike RNNs - faster on GPUs

> Stacked layers (xN)
6 encoders + 6 decoders originally

> Powers modern LLMs
GPT, Claude, Gemini, Llama
